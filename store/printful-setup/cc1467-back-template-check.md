# CC1467 regular Back template check

29 October 2026. Read-only inspection of the [official linked Front and back ZIP](https://printful.s3-accelerate.amazonaws.com/upload/guideline/Front%20and%20back.zip). HTTP 200, `application/zip`, 641,272 bytes. ZIP SHA256: `a0d0842c4bc600ce3826a1e317873feb80af237dbce1f4086c551e215cad0078`.

The archive contains **`Front and back/11.5x15.3 back print.png`** and **`11.5x15.3 back print.psd`**, alongside separate front templates. The back PNG was visually inspected: it shows a back garment diagram with an **11.5 × 15.3 inch** maximum print area, equivalent to **292.1 × 388.62 mm**. The approved 240 × 65.761 mm artwork fits comfortably. The guide instructs removal/hiding of guide layers from the final graphic.

The PNG is a generic shirt diagram and does not itself name CC1467 or size S. Root separately observed that the authenticated CC1467 designer offers **regular Back for S** and links this archive. Together, those observations support that regular Back route; they do not support Large Back for S.

There is a minor documentation discrepancy: the public/authenticated table's S height is 39.37 cm (15.5 inches), while this back template says 15.3 inches. Use the conservative template height of 388.62 mm; the small approved artwork fits either bound. The exact vertical position still comes from the CC1467 designer, including hood coverage.

Back PNG SHA256: `48435c633ab6501dc1db1701ef9f730a8c448d9e7cf8502a6467da76a7985f71`. Both PNG templates were extracted unchanged to a temporary inspection directory; production artwork was untouched.

Neither PNG provides chest-embroidery/back-print combination guidance. A fresh official Help Center search found no explicit permission or prohibition for that exact combination. It remains a separate authenticated designer check; this ZIP resolves the existence and bounds of a back-print template, not mixed-technique support.
