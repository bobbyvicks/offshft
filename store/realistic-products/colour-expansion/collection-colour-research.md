Checked **29 October 2026** against the exact Printful pages in `store/picks.md` and the selected secondary blank pages. The first five families below were inspected through the **live product colour selectors**, with **Embroidery** selected, in Printful's **Canada delivery context**. ## Reproducing the secondary-selector check

The official pages' `:product-id` attributes identify 6245CM as **206**, 31-069 as **952**, BA671 as **807**, and 6030 as **593**. The public catalogue JavaScript exposes a read-only GraphQL operation at `https://www.printful.com/graphql?getProductPickerData`. No login, cookies, credentials or store ID were used.

Send `Content-Type: application/json` and `X-PF-Language: en_CA`. The first 6245CM check used `en_US`; the other three used `en_CA`. A language header establishes locale, not shipping eligibility.

```json
{
  "operationName": "getProductPickerData",
  "variables": { "productId": 593 },
  "query": "query getProductPickerData($productId: Int!, $storeId: Int) { singleProducts { productPickerData(productId: $productId, storeId: $storeId) { productId variantAvailability sizes { value title } techniques { value title values { value title } } colors { value title extra { codes tooltip } } } } }"
}
```

Substitute the product ID. Colour data comes from `data.singleProducts.productPickerData.colors`; technique support from `techniques`. `variantAvailability` is JSON-encoded text that needs another parse. The returned variants reported stock/fulfilment availability at the check, but this is not a reservation or destination-specific delivery promise.

The 6030 placement check used `getGuidelinesAndTemplates` against the same endpoint, reading `singleProducts.singleProduct(productId: 593).productDescription`, `productSpecs` and `guidelinesAndTemplates.templates`. Preserve the description/template contradiction in the production handoff.

## Final selected size and colour check

The follow-up public picker check covers all twelve selected blanks. Its complete responses are saved in `verification/supplier-size-colour-availability.json`; `verification/independent-matrix-review.md` checks the final matrix against those responses. The final jacket expansion uses **Light Blue**.

- Hoodies 5161, 1567 and 1467, and crewneck 1466: selected colours support S–3XL.
- Heavyweight T-shirt 1717: selected colours support S–3XL for the selected embroidery technique. The supplier also lists 4XL, which this task does not add.
- Pocket T-shirt 6030, sweatpants 1469 and Champion CO200 jacket: S–2XL only.
- Hats: One size. Exact selected colours are those in `colour-plan.json`.

The untouched Shopify baseline contains six unsupported 3XL records: one per sweatpants and jacket product. The owner explicitly approved removing those six options. Their exact IDs are listed in `colour-plan.json`; final verification must require their absence and preserve the other 136 original IDs. Both colours of these garments stop at 2XL. The final target is **253 variants: 136 retained originals + 117 new variants**, all matching the selected supplier colour/size rows. Actual Shopify removal is verified separately from this local plan.

The selected rows have no stock/general-availability failures or embroidery exclusions in the public data. Some 1717 rows have a literal `T-SHIRT` technique exclusion; the independent review records it without treating it as an embroidery failure. This remains a public catalogue check without an account-specific destination quote, stock reservation or Printful fulfilment sync.
