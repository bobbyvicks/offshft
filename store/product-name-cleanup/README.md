# Design-only product names — 2 November 2026

The owner requested removing the item/garment name from every product title. All 47 active listings now use only their design names, for example `Punched Out.`, `Banked Time.`, `Time Well Spent.` and `OFF SHFT Golf Club`. Existing design punctuation is retained. The canonical logo design remains named `OFF SHFT Logo`.

Banked Time was changed in the preceding single-product pass; the other 46 titles were saved together through Shopify's native bulk editor. Three archived drafts were excluded. `title-plan.json` records each product ID and its exact before/after title. Future catalogue generation must retain these design-only titles rather than restoring garment suffixes from historical listing drafts.

A fresh public catalogue reread verified all 47 names, all 1,153 variants and all 335 image records. Product handles, descriptions, types, tags, prices, images and style/size/colour/finish options are unchanged. Main Shop garment-category cards remain category names (such as Pocket Tees and Oversized Hoodies), preserving the requested separation between bases. Individual product headings display the design name alone.

`verification.json` records the comparison; `live-design-only-title.png` shows the live Punched Out product heading. No Printful production or fulfilment changes were required.
